DECISION RULES APPLIED (same for all rated studies)
Pre-agreed: not reported -> unclear (unless the omission is itself a flaw); overall = low only if all four low, high if any high, otherwise unclear.
Calibration choice (prompt Step 1, D4): calibration not assessed at all -> D4 HIGH. A calibration plot, slope/intercept, Hosmer-Lemeshow, binned lift chart or a Brier score counts as an assessment (Brier accepted per this protocol). Calibration described in Methods but no result reported = not assessed.
  RULE CHANGE (declared): the first pass did not accept a Brier score alone. Re-applied to all 48: affected studies were Peng 2024 (unchanged, D4 high for univariable selection), Chen 2026 (unchanged, univariable selection) and Sun 2026 (D4 high -> unclear; overall high -> unclear). All other calibration judgements were unaffected.
D1: model for use before treatment developed only on cycles reaching embryo transfer (or only clinical pregnancies) -> high; unjustified exclusion >10% for missing data / loss to follow-up, or exclusions made but not quantified -> unclear.
D2: any predictor not available at the intended decision point (embryos transferred in a pre-treatment model, post-transfer hCG, outcome-dependent totals) -> high; predictor list not reported -> unclear.
D3: live birth defined (threshold, numerator, denominator) -> low; only named -> unclear; composite outcome (live birth + ongoing pregnancy) or sample conditioned on clinical pregnancy -> high; CLBR with remaining frozen embryos counted as failures or follow-up/censoring not described -> unclear.
D4 high triggers: no calibration; apparent performance only; imputation/scaling/feature selection/rebalancing fitted before the split or outside CV; evaluation on rebalanced or synthetic data; predictor selection by univariable significance (PROBAST 4.5); test data used to choose the model or the split; only hold-out/external set with clearly <100 events and no resampling validation. D4 unclear: contradictory or missing description of these steps, complete-case exclusion >10% without justification, patient-level independence not addressed.
Several models in one study (stage-specific, pre/post-treatment, cohort-specific): each domain rated at the worse model; intended use recorded for the first-listed model; the implied decision point of later models is given in the 'Intended use' column.
Intended use: 'as presented' = the authors' stated decision point ('not stated' if none); 'implied by predictors' added when the latest-timed predictor implies a different point.
Wrong/missing file: not rated (Borji 2025).
Extraction scope: every live-birth AUC reported for an evaluation set (test, validation, cross-validation, bootstrap, temporal, external) for each model in the main text and tables; training/apparent AUCs included only when they are the only estimate or the authors' headline number. Subgroup AUCs and non-live-birth outcomes (clinical pregnancy) excluded. Event counts are given only when stated in the article; derived counts are marked 'not reported'.
Evidence file: text in double quotes is verbatim from the PDF text layer (<=24 words; whitespace normalised); rows marked [number/summary, not a quotation] give an exact number or a summary, used where the source is an image (Chinese papers, figures) or where the evidence is an absence ('Not reported ... location not found').
